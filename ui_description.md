# UI-концепции ClinicBook

Концепции сгенерированы в **v0.dev** (Text-to-UI). Ниже — три варианта, отличающихся стилем и компоновкой, с преимуществами, недостатками и обоснованием выбора.

---

## Концепция 1. Minimalist (выбрана)

**Стиль:** минимализм, много воздуха, тонкие границы, спокойные цвета.

**Палитра:** белый фон, тёмно-серый текст (#111827), акцент — медицинский синий (#2563EB), зелёный для подтверждений.

**Компоновка:**
- Верхняя навигация: логотип, «Мои записи», имя пользователя.
- Главный экран: карточка «Ближайший визит» + кнопка «Записаться».
- Запись — пошаговый выбор: специалист → дата → слот → подтверждение.
- Список визитов — простая таблица с бейджами статуса.

**Преимущества:**
- Понятен пожилым пациентам.
- Быстро разрабатывается, легко адаптируется под мобильные.
- Акцент на главном действии — записи.

**Недостатки:**
- Визуально сдержанный.
- Мало «эмоций» для маркетинга.

**Пример кода (Tailwind):**
```html
<div class="max-w-md mx-auto bg-white rounded-2xl shadow-sm p-6">
  <p class="text-sm text-gray-500">Ближайший визит</p>
  <p class="text-xl font-semibold text-gray-900">Терапевт, 12 мая, 10:30</p>
  <button class="mt-4 w-full bg-blue-600 text-white rounded-lg py-2">
    Записаться снова
  </button>
</div>
Концепция 2. Vibrant
Стиль: яркий, дружелюбный, градиенты, крупные иконки, скруглённые карточки.

Палитра: градиент teal → indigo, белые карточки, цветные бейджи.

Компоновка:

Боковое меню с иконками (запись, визиты, профиль).

Дашборд из виджетов: «Ближайший визит», «История», «Врачи».

Запись — горизонтальный степпер с крупными кнопками.

Преимущества:

Дружелюбный вид, хорошо для мобильных.

Высокая вовлечённость.

Недостатки:

Может отвлекать и казаться несерьёзным для медицинского сервиса.

Сложнее в поддержке.

Пример кода:

html
<div class="bg-gradient-to-r from-teal-500 to-indigo-600 text-white rounded-2xl p-6">
  <p class="text-sm opacity-80">Сегодня</p>
  <p class="text-2xl font-bold">Терапевт, 10:30</p>
  <button class="mt-4 bg-white text-indigo-600 rounded-lg px-4 py-2">
    Подтвердить
  </button>
</div>
Концепция 3. Corporate
Стиль: строгий, «клинический», плотные таблицы, чёткие фильтры.

Палитра: тёмно-синий (#1E3A8A), серые панели, белые таблицы.

Компоновка:

Левое меню, верхняя панель с фильтрами.

Основной экран — таблица записей: пациент, врач, дата, статус.

Форма записи — отдельная страница с полями.

Преимущества:

Удобно для администратора и врача.

Много данных на экране.

Легко масштабируется.

Недостатки:

Тяжёлый для пациента.

Менее приятен на мобильных.

Пример кода:

html
<table class="min-w-full bg-white border">
  <thead class="bg-slate-100">
    <tr>
      <th class="px-4 py-2 text-left">Пациент</th>
      <th class="px-4 py-2 text-left">Врач</th>
      <th class="px-4 py-2 text-left">Дата</th>
      <th class="px-4 py-2 text-left">Статус</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td class="px-4 py-2 border-t">Иван Петров</td>
      <td class="px-4 py-2 border-t">Терапевт</td>
      <td class="px-4 py-2 border-t">12.05, 10:30</td>
      <td class="px-4 py-2 border-t text-green-600">Подтверждён</td>
    </tr>
  </tbody>
</table>
Обоснование выбора
Выбрана Концепция 1 (Minimalist).

Факторы:

Пациенты — часто не технически подкованные люди; простота важнее яркости.

Акцент на главном действии — записи на приём.

Легко адаптируется под мобильные устройства (большинство пациентов будут открывать с телефона).

Быстрая разработка MVP.

Альтернативы отклонены:

Vibrant — слишком «игровой» для медицинского сервиса.

Corporate — оптимален для админ-панели, но не для пациента; элементы таблицы из него можно частично перенести в раздел администратора.
