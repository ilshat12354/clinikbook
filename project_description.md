# ClinicBook — онлайн-запись на приём в клинику

## 1. Идея проекта

**ClinicBook** — веб-приложение для онлайн-записи пациентов на приём к врачам небольшой частной клиники. Пациент выбирает специалиста, дату и время, получает подтверждение. Администратор видит расписание и управляет записями.

## 2. Проблема

Сейчас запись ведётся по телефону. Это приводит к:
- занятости администратора и долгому ожиданию;
- ошибкам при переносе записей;
- отсутствию у пациента информации о своих визитах;
- потерям записей при отмене.

## 3. Целевая аудитория

| Роль | Описание |
|---|---|
| Пациент | Хочет записаться к врачу без звонков и видеть свои визиты |
| Администратор | Хочет управлять расписанием и записями |
| Врач | Хочет видеть своё расписание на день/неделю |

## 4. Ключевые функции MVP

1. **Онлайн-запись на приём** — выбор врача, даты, свободного слота и подтверждение.
2. **Личный кабинет пациента** — список предстоящих и прошедших визитов, отмена записи.
3. **Панель администратора** — просмотр и управление расписанием, отмена/перенос записей.

## 5. Ценность

- Пациент записывается 24/7 без звонков.
- Администратор экономит время и меньше ошибается.
- Клиника снижает число неявок за счёт напоминаний и удобной отмены.

## 6. Технологический стек (предварительно)

- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express + TypeScript
- БД: PostgreSQL + Prisma ORM
- Аутентификация: JWT, роли `patient`, `admin`, `doctor`
- Инфраструктура: Docker Compose
